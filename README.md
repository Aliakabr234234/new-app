# ResourceFlow - Frontend & Backend

A comprehensive resource management application built with React, TypeScript, and Express.js.

## Project Structure

```
├── src/                    # Frontend (React + Vite)
├── backend/               # Backend (Express + Node.js)
├── package.json          # Frontend dependencies
├── tsconfig.json         # Frontend TypeScript config
├── vite.config.ts        # Vite configuration
└── vercel.json           # Vercel deployment config
```

## Frontend Setup

```bash
npm install
npm run dev    # Development
npm run build  # Production build
```

## Backend Setup

```bash
cd backend
npm install
npm run dev    # Development
npm run build  # Production build
```

## Deployment

Frontend is deployed on Vercel. Backend requires separate hosting setup.
